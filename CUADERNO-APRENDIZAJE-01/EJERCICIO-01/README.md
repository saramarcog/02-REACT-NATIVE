## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:
'View' actua como un contenedor que sirve para agrupar y organizar elementos. En cambio, 'Text' se usa exclusivamente para escribir y mostrar palabras por pantalla
